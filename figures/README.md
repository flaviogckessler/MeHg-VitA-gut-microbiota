### Figure 6

- Figure 6 is a KO-only functional-prediction figure. It uses the canonical PICRUSt2 [`kegg_ortholog_abundance.tsv`](../results/functional_prediction/batch01_iontorrent_dams-f0_f1-pnd21/kegg_ortholog_abundance.tsv) for batch 01 and corresponding [`kegg_ortholog_abundance.tsv`](../results/functional_prediction/batch02_illumina-miseq_f1-f2_pnd365/kegg_ortholog_abundance.tsv) for batch 02. EC and MetaCyc matrices, weighted NSTI quality-control files, and `kegg_ortholog_abundance_legacy_ko2.tsv` checkpoints are not figure inputs.
- All panels join matrix columns to the canonical [`sample_manifest_all_batches.csv`](../data/metadata/sample_manifest_all_batches.csv) and honor `include_primary_analysis`. Panel A analyzes 34 included F1-PND21 samples from batch 01 (thereby excluding `10F` and `22F`); panels B and C analyze the 24 F1-PND365 and 24 F2-PND365 samples from batch 02, respectively. The undocumented matrix column `t3` is excluded because it has no canonical metadata row.
- Panel A is generated by [`generate_figure_6_a.R`](Figure_6/generate_figure_6_a.R), panel B by [`generate_figure_6_b.R`](Figure_6/generate_figure_6_b.R), and panel C by [`generate_figure_6_c.R`](Figure_6/generate_figure_6_c.R). They share the audited KO loading, `ggpicrust2::ko2kegg_abundance()`, ALDEx2, offline KEGG annotation, corrected four-group `pathway_errorbar3()`, and plotting code in [`figure_6_common.R`](Figure_6/figure_6_common.R).
- The statistical refactor preserves the legacy four-group ALDEx2 GLM and six-treatment-contrast Bonferroni multiplier. A fixed seed (`20260809`) makes the Monte Carlo analysis reproducible. Because the legacy final analysis did not set a seed, the final-figure pathway list is also treated as an explicit checkpoint with a narrow 0.01 adjusted-p boundary tolerance; panel B records the seeded boundary-only Betalain-biosynthesis result as excluded because it was not present in the supplied final figure.
- Generated panels are [`Figure6A_generated.png`](Figure_6/output/Figure6A_generated.png), [`Figure6B_generated.png`](Figure_6/output/Figure6B_generated.png), and [`Figure6C_generated.png`](Figure_6/output/Figure6C_generated.png). [`Figure_6_FinalFigure.png`](Figure_6/output/Figure_6_FinalFigure.png) is the supplied manually assembled reference composite used for visual validation.
- [`validate_figure_6.R`](Figure_6/validate_figure_6.R) checks canonical sources, sample strata, exclusions, provenance placement, script parsing, reference dimensions, and generated PNGs. Set `FIGURE6_FULL_VALIDATION=true` before running it to repeat all three seeded ALDEx2 analyses; the default validation is intentionally fast.
- The portable workflow is derived from the unchanged [`Picrust_mestrado_Alberto.R`](../scripts/legacy_scripts/Picrust_mestrado_Alberto.R). Its multi-group plotting function could misalign filtered DAA rows, pathway order, p-values, and group summaries. The replacement aligns by explicit feature/group keys and does not calculate a two-group fold change for the four-group design.
- The upstream Linux-terminal reconstruction remains documented in [`picrust2_workflow.md`](../scripts/04_functional_prediction/picrust2_workflow.md), derived from the unchanged [`Script_picrust_mehg.txt`](../scripts/legacy_scripts/Script_picrust_mehg.txt) command log.
