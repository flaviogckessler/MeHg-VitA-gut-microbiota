# Main figures

## Output policy

- Generate scripted figures as lightweight, readable PNG files.
- Do not generate new TIFF files; preserve manually supplied TIFF files as reference artifacts.

## Available sources and generation

### Figure 1

- Source: [`Figure_1/Experimental_Procedures.pptx`](Figure_1/Experimental_Procedures.pptx).
- Generation: the full figure was prepared in Microsoft PowerPoint and exported as [`Experimental_Procedures.png`](Figure_1/Experimental_Procedures.png).

### Figure 3

- Panels A-C use processed ASV tables in [`data/processed/`](../data/processed/) and canonical manifests in [`data/metadata/`](../data/metadata/). They are generated by [`generate_figure_3_abc.R`](Figure_3/generate_figure_3_abc.R), a portable refactor of [`Abundancias_Barras_Mestrado.R`](../scripts/legacy_scripts/Abundancias_Barras_Mestrado.R).
- Panels D-G use [`results/alpha_diversity/`](../results/alpha_diversity/) and the canonical manifests. They are generated by [`generate_figure_3_dg.R`](Figure_3/generate_figure_3_dg.R), a portable refactor of [`Alpha_Diversity.R`](../scripts/legacy_scripts/Alpha_Diversity.R).
- Panels H-K use [`results/taxon_relative_abundance/`](../results/taxon_relative_abundance/) and the canonical manifests. They are generated by [`generate_figure_3_hk.R`](Figure_3/generate_figure_3_hk.R), a portable refactor of [`Abundancia_boxplots.R`](../scripts/legacy_scripts/Abundancia_boxplots.R).
- Each generator has a matching `validate_figure_3_*.R` script. PNG panels are written to `Figure_3/output/`, where `FinalFigure3.png` is the manually assembled Photoshop composite.

### Figure 4

- Panel A (dams, F0) uses [`batch01_iontorrent_dams-f0_f1-pnd21_taxon_relative_abundance.csv`](../results/taxon_relative_abundance/batch01_iontorrent_dams-f0_f1-pnd21_taxon_relative_abundance.csv) and the corresponding canonical [`sample_manifest.csv`](../data/metadata/batch01_iontorrent_dams-f0_f1-pnd21/sample_manifest.csv). It is generated by [`Figure_4/generate_figure_4_a.R`](Figure_4/generate_figure_4_a.R).
- Panel B (F1, PND21; females and males) uses the same batch 1 [`taxon-relative-abundance table`](../results/taxon_relative_abundance/batch01_iontorrent_dams-f0_f1-pnd21_taxon_relative_abundance.csv) and [`sample manifest`](../data/metadata/batch01_iontorrent_dams-f0_f1-pnd21/sample_manifest.csv). It is generated by [`Figure_4/generate_figure_4_b.R`](Figure_4/generate_figure_4_b.R).
- Panel C (F1, PND365; females and males) uses [`batch02_illumina-miseq_f1-f2_pnd365_taxon_relative_abundance.csv`](../results/taxon_relative_abundance/batch02_illumina-miseq_f1-f2_pnd365_taxon_relative_abundance.csv) and the corresponding canonical [`sample_manifest.csv`](../data/metadata/batch02_illumina-miseq_f1-f2_pnd365/sample_manifest.csv). It is generated by [`Figure_4/generate_figure_4_c.R`](Figure_4/generate_figure_4_c.R).
- Panel D (F2, PND365; females and males) uses the same batch 2 [`taxon-relative-abundance table`](../results/taxon_relative_abundance/batch02_illumina-miseq_f1-f2_pnd365_taxon_relative_abundance.csv) and [`sample manifest`](../data/metadata/batch02_illumina-miseq_f1-f2_pnd365/sample_manifest.csv). It is generated by [`Figure_4/generate_figure_4_d.R`](Figure_4/generate_figure_4_d.R).
- The panel workflows are portable refactors of [`Heatmap_Zscore_MestradoAlberto.R`](../scripts/legacy_scripts/Heatmap_Zscore_MestradoAlberto.R). Preserved `Signif_*.csv` tables under [`results/legacy_summary_tables/figure_4/`](../results/legacy_summary_tables/figure_4/) are validation checkpoints rather than primary inputs. [`validate_figure_4.R`](Figure_4/validate_figure_4.R) checks the canonical sources, significant taxa, treatment means, z-scores, checkpoints, and generated PNG files.
- Generated panels are written to [`Figure_4/output/`](Figure_4/output/). [`Figure_4_FinalFigure.png`](Figure_4/output/Figure_4_FinalFigure.png) is the manually assembled Photoshop reference composite.
