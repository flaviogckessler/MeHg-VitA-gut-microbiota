# Main figures

## Output policy

- Generate scripted figures as lightweight, readable PNG files.
- Do not generate new TIFF files; preserve manually supplied TIFF files as reference artifacts.

## Software, R packages, and sample-size convention

`N` denotes biological samples (animals), not ASVs, taxa, pathways, or KOs. For microbiome workflows, counts are taken after applying `include_primary_analysis`; this excludes batch-01 samples `10F` and `22F` and the undocumented batch-02 column `t3`. Base-R workflows explicitly load the relevant packages distributed with R [@r-core].

### Figure 6

- Figure 6 is a KO-only functional-prediction figure. It uses the canonical PICRUSt2 [`kegg_ortholog_abundance.tsv`](../results/functional_prediction/batch01_iontorrent_dams-f0_f1-pnd21/kegg_ortholog_abundance.tsv) for batch 01 and corresponding [`kegg_ortholog_abundance.tsv`](../results/functional_prediction/batch02_illumina-miseq_f1-f2_pnd365/kegg_ortholog_abundance.tsv) for batch 02. EC and MetaCyc matrices, weighted NSTI quality-control files, and `kegg_ortholog_abundance_legacy_ko2.tsv` checkpoints are not figure inputs.
- All panels join matrix columns to the canonical [`sample_manifest_all_batches.csv`](../data/metadata/sample_manifest_all_batches.csv) and honor `include_primary_analysis`. Panel A analyzes 34 included F1-PND21 samples from batch 01 (thereby excluding `10F` and `22F`); panels B and C analyze the 24 F1-PND365 and 24 F2-PND365 samples from batch 02, respectively. The undocumented matrix column `t3` is excluded because it has no canonical metadata row.
- Panel A is generated by [`generate_figure_6_a.R`](Figure_6/generate_figure_6_a.R), panel B by [`generate_figure_6_b.R`](Figure_6/generate_figure_6_b.R), and panel C by [`generate_figure_6_c.R`](Figure_6/generate_figure_6_c.R). They share the audited KO loading, `ggpicrust2::ko2kegg_abundance()`, ALDEx2, offline KEGG annotation, corrected four-group `pathway_errorbar3()`, and plotting code in [`figure_6_common.R`](Figure_6/figure_6_common.R).
- The reconstructed historical Figure 6 environment uses `ggpicrust2` 2.0.0 and `ALDEx2` 1.28.1. The legacy script points to the same user's R 4.2 library, the surviving package metadata identify those versions, both installations predate the retained final figure, and the archived KEGG reference independently matches `ggpicrust2` 2.0.0. R 4.2.x, likely R 4.2.1, is retained as contextual evidence. Because no historical `sessionInfo()`, lockfile, or GitHub commit SHA survives, these are evidence-backed reconstructed versions rather than a cryptographically locked environment.
- The statistical refactor preserves one four-treatment omnibus ALDEx2 GLM test per pathway and intentionally performs no post-hoc pairwise tests. For pathway selection, the author defined an additional conservative sixfold rule motivated by the six possible pairs among four treatments: `p_author = min(1, 6 * p_raw_omnibus)`. This is an author-defined penalty on each omnibus p-value, not an adjustment of calculated pairwise tests. The package-returned adjusted value is retained separately as `package_p_adjust`; the legacy-compatible `p_adjust` column contains `p_author`. A fixed seed (`20260809`) makes the Monte Carlo analysis reproducible. Because the legacy final analysis did not set a seed, the final-figure pathway list is also treated as an explicit checkpoint with a narrow 0.01 sixfold-rule boundary tolerance; panel B records the seeded boundary-only Betalain-biosynthesis result as excluded because it was not present in the supplied final figure.
- Generated panels are [`Figure6A_generated.png`](Figure_6/output/Figure6A_generated.png), [`Figure6B_generated.png`](Figure_6/output/Figure6B_generated.png), and [`Figure6C_generated.png`](Figure_6/output/Figure6C_generated.png). [`Figure_6_FinalFigure.png`](Figure_6/output/Figure_6_FinalFigure.png) is the supplied manually assembled reference composite used for visual validation.
- [`validate_figure_6.R`](Figure_6/validate_figure_6.R) checks canonical sources, sample strata, exclusions, provenance placement, script parsing, reference dimensions, and generated PNGs. Set `FIGURE6_FULL_VALIDATION=true` before running it to repeat all three seeded ALDEx2 analyses; the default validation is intentionally fast.
- The portable workflow is derived from the unchanged [`Picrust_mestrado_Alberto.R`](../scripts/legacy_scripts/Picrust_mestrado_Alberto.R). Its multi-group plotting function could misalign filtered DAA rows, pathway order, p-values, and group summaries. The replacement aligns by explicit feature/group keys and does not calculate a two-group fold change for the four-group design.
- The upstream Linux-terminal reconstruction remains documented in [`picrust2_workflow.md`](../scripts/04_functional_prediction/picrust2_workflow.md), derived from the unchanged [`Script_picrust_mehg.txt`](../scripts/legacy_scripts/Script_picrust_mehg.txt) command log.

### Shared Figures 7, 8, and S8-S16 source workflow

- [`generate_kegg_pathway_ko_z_scores.R`](../scripts/04_functional_prediction/generate_kegg_pathway_ko_z_scores.R) generates all 19 clean KO-level source tables from canonical PICRUSt2 KO abundance matrices and cohort/treatment labels in the canonical manifest; it does not read legacy source tables.
- The generated source tables are stored in the batch-specific directories [`batch01_iontorrent_dams-f0_f1-pnd21/kegg_pathway_ko_z_scores/`](../results/functional_prediction/batch01_iontorrent_dams-f0_f1-pnd21/kegg_pathway_ko_z_scores/) and [`batch02_illumina-miseq_f1-f2_pnd365/kegg_pathway_ko_z_scores/`](../results/functional_prediction/batch02_illumina-miseq_f1-f2_pnd365/kegg_pathway_ko_z_scores/).
- The KEGG pathway panels—often panels A, B, C, and D—were generated manually at [`https://www.kegg.jp/pathway/mapxxxxx`](https://www.kegg.jp/pathway/mapxxxxx), where `xxxxx` represents the five-digit pathway code used in the individual figure. One pathway view was prepared for each applicable exposure group, and its boxes were colored using the matching `CN`, `VitA`, `MeHg`, or `VitA+MeHg` column in the relevant KO z-score CSV as the numerical reference. These manually prepared pathway panels are not generated by the R heatmap scripts.
- [`validate_kegg_pathway_ko_z_scores.R`](../scripts/04_functional_prediction/validate_kegg_pathway_ko_z_scores.R) independently checks the 19 clean outputs against their unchanged legacy CSV checkpoints.
- Main-figure heatmap panels 7E and 8E are generated by their figure-specific scripts above. The ten supplementary heatmaps in S8-S16 use the shared portable renderer [`figure_s8_s16_common.R`](../supplementary_figures/figure_s8_s16_common.R), nine independently executable figure entry points, and the end-to-end [`validate_figure_s8_s16.R`](../supplementary_figures/validate_figure_s8_s16.R) validator.
- The supplied final composites are retained under each figure's `output/` directory as visual references. See [`supplementary_figures/README.md`](../supplementary_figures/README.md) for the complete S8-S16 panel/source map, commands, output filenames, and S15 two-cohort exception.
